# webCut V0.6.4

文档更新：2026-10-18。以下功能以 `main` 分支最新源码为准，旧安装包可能尚未包含。

![webCut 界面](https://raw.githubusercontent.com/feeday/webCut/main/2.png)

轻量浏览器音视频、图片剪辑器。视频、音频与图片的预览、编辑和导出主要在访问者浏览器本地完成；部分格式转换使用 FFmpeg.wasm。仓库保留部分历史 ASR 相关源码，但视频页顶部不再提供语音识别入口。

源码：<https://github.com/feeday/webCut>

## 当前功能

- 顶部统一“导入素材”菜单、“画面裁剪”、“字幕样式”、“导出”和“项目首页”按钮（已移除独立语音识别跳转按钮）

- 横屏 / 竖屏视频自适应预览
- 多视频顺序拼接、时长裁剪、分割、删除、撤销
- 视频画面框选裁剪、像素微调、裁剪结果预览及裁剪后导出
- 视频原声音频波形
- 独立音频轨与纯音频工程
- 独立深色纯音频工作台：录音输入、波形选段、线性 / 对数频谱、单张纵向对数声谱瀑布图、实倒谱、相位图、RMS 能量包络
- 音频图谱实时指标、平滑、显示增益、dB 范围、配色、暂停与 PNG 截图
- 纯音频保留选段、撤销裁剪、增益、淡入淡出、归一化、倒放、试听及 WAV / MP3 / FLAC / M4A / AAC / OGG / OPUS / WebM 导出
- 无需预先导入视频即可添加图片，支持独立图片工程
- 多图片图层覆盖
- 图片在预览区直接拖动、缩放
- 图片图层置顶 / 上移 / 下移 / 置底
- 时间轴缩放、Ctrl + 滚轮缩放
- 逐帧查看
- 故事板 / 按间隔抽帧导览
- SRT / VTT 字幕导入、导出、预览和双击编辑
- 字幕字体、字号、颜色、粗细和位置设置，支持烧录进视频
- 图像导出：PNG、JPEG、WebP、BMP（浏览器 Canvas 生成；依赖浏览器格式支持）
- 浏览器本地 FFmpeg.wasm 导出
- 多种画布尺寸与 contain / cover 适配
- Windows 网页版 / CentOS 网页版 / Windows EXE 桌面版
- 未导入任何视频、音频或图片时，在预览区域内部显示 Google AdSense 广告；导入素材后隐藏，恢复空工程后重新显示（实际投放由 Google 决定）
- Windows EXE 支持“另存为”选择导出路径
- Windows 免安装 Portable EXE，双击直接运行

## 快速使用

1. 启动网页版本或最新构建的 EXE，在顶部 **导入素材** 中选择 **打开视频 / 音频（新工程）**，也可直接使用 **添加图片** 创建纯图片工程；需要叠加素材时选择 **追加视频**、**添加图片** 或 **追加音频**。
2. 在时间轴选择片段进行时长裁剪、分割或拼接。图片图层可以独立拖动、缩放与调整层级，不要求先有视频。
3. 需要裁掉视频画面边缘时，点击 **画面裁剪**，在裁剪窗口选择区域后点击 **应用裁剪**；此功能针对选中的视频片段。
4. 需要字幕时，从右侧 **导入字幕** 加载 UTF-8 编码的 SRT / VTT；双击字幕块可以修改文字和起止时间。点击 **字幕样式** 设置字体、大小、颜色和位置。
5. 点击 **导出**，选择 **视频 / 仅音频 / 图像** 和目标格式。图像支持 PNG、JPEG、WebP、BMP，默认输出当前播放头位置的图像图层合成结果。视频导出可选择是否烧录字幕。
6. 空白工程的广告只显示在预览画面内部，不另占编辑器行高；导入视频、音频或图片后自动隐藏。广告填充取决于 AdSense，不能保证每次都有广告。

## 纯音频工作台

独立音频工作台通过 `audio.html` 直接访问；主视频页已不显示该顶部入口。导入浏览器可解码的音频，或点击 **开始录音** 并允许麦克风权限；停止后自动载入。录音最长 10 分钟，需要 HTTPS / localhost 与浏览器录音支持。

深色多图布局参考音频分析仪：首屏为宽幅波形与纵向对数瀑布图；其余保留线性 / 对数频谱、实倒谱、相位图和 RMS。横向声谱与 Mel 图已移除，瀑布图只保留一张。支持显示增益、频谱平滑、dB 范围、三种瀑布配色，以及单图 PNG / 全部图谱截图。显示增益只影响波形，不改变采集音频或导出增益；暂停图谱不停止录音。RMS / Peak 为数字满幅参考的 dBFS，不是校准的物理声压级。

拖动波形选择区间，或填写开始 / 结束时间；点击波形定位并观察当前帧频谱、实倒谱及相位图。图谱支持完整音频 / 选中区间、1024 / 2048 / 4096 FFT。声谱图在独立 Worker 中计算，长音频最多显示 700 个时间窗。录音过程中实时显示混合麦克风波形、频谱、瀑布与 RMS；停止后重新生成完整图谱。麦克风实时相位图使用混合单声道，停止录音后按实际文件声道显示；单声道或左右完全相同的音频显示对角线属于正常现象。

拖动波形或填写开始 / 结束时间后，点击 **保留选段（裁剪）** 将两端裁掉，保留的音频重新显示在波形中。支持连续裁剪和 **撤销裁剪**（最多 10 步），裁剪不覆盖导入文件。音频工作台当前不显示 Qwen ASR 识别界面。

右侧可设置增益、淡入淡出、98% 峰值归一化和倒放；**播放选段** 播放原音频，**试听处理结果** 与 **导出音频** 应用处理设置。导出范围可选择 **当前选段** 或 **完整当前音频**；完成裁剪后选择完整当前音频即可保存保留的部分。图谱始终分析当前原始 PCM，声谱图不提供身份识别或声纹鉴定。

导出格式支持 WAV、MP3、FLAC、M4A（AAC）、AAC、OGG（Vorbis）、OPUS、WebM（仅 Opus 音频）。WAV 在浏览器直接生成；其余格式用 FFmpeg.wasm 本地转换，首次需要从 `esm.sh`、`cdnjs.cloudflare.com`、`unpkg.com` 下载转码组件，音频文件不上传。有损格式可选 64–320 kbps；编码器可能按源采样率、声道数调整实际码率或拒绝不合适的组合。

处理中间 PCM 为 16-bit；WAV / FLAC 基于此 PCM 导出。保留浏览器解码后的声道数；AudioContext 可能将输入重采样为设备采样率，Opus / WebM 编码为 48 kHz。不支持浏览器解码的输入需要先转换成可解码格式。

音频工作台使用独立页面，不改动视频剪辑、字幕、裁剪与视频导出逻辑。直接访问音频页时，主视频页工程不会因此改变；音频页左上角链接可另行打开视频页面。桌面版已加入音频文件打包清单，旧 EXE 需重新构建；麦克风支持取决于系统 WebView 权限。

## 独立图片工程与图像导出

- 在顶部 **导入素材 → 添加图片** 选择图片，无需先导入视频。图片以时间轴图层形式管理，可调节显示位置、尺寸、图层顺序、起止时间。
- 将播放头移动到需要输出的图片片段范围内，选择 **导出 → 类型：图像**，再选择 PNG、JPEG、WebP 或 BMP。浏览器会通过 Canvas 绘制当前播放头位置上的图像图层并下载单张图片。
- 导出弹窗保留画布宽高设置；具体效果以当前浏览器的 Canvas 编码与图层绘制能力为准。图片输出与视频 FFmpeg.wasm 转码是不同处理流程。
- 只有图片的工程也可以打开导出弹窗；如果播放头位置没有有效图片片段，会提示调整播放头。

## 空白预览广告

- 无视频、音频和图片素材时，预览灰色区域内部可能展示 AdSense 广告（广告位 `1907914008`）。
- 载入任意视频、音频或图片后，整个广告容器隐藏，不额外占据预览高度，也不改变竖屏预览和时间轴布局。
- 清空全部素材后可以恢复广告容器；是否能加载或填充广告取决于 Google AdSense 及浏览器设置。

## 视频画面裁剪

1. 导入视频，在时间轴上选中需要裁剪的视频片段。
2. 点击顶部 **画面裁剪**，在视频画面上按住鼠标拖出要保留的矩形。
3. 拖动矩形内部可移动选区，拖四角可调整大小；也可以输入左边距 X、上边距 Y、宽和高。下方会显示裁剪结果预览。
4. 点击 **应用裁剪**，再点击 **导出 → 开始导出**。默认画布采用首段视频的裁剪尺寸。

- 首次打开（或点击“恢复完整画面”后）可以直接从画面任意位置拖框；已有选区时，可从框外重新绘制。
- 裁剪作用于当前视频片段，分割片段时继承裁剪设置。多个片段可分别裁剪；合成时统一到导出画布尺寸。
- 点击“恢复完整画面”后再应用可取消裁剪，也可用“撤销”恢复上一状态。直接关闭窗口或点“取消”不会修改工程。
- 为兼容视频编码，裁剪坐标和尺寸自动对齐为偶数像素，最小 2×2。选择精确尺寸后可在字段中核对。
- 主剪辑预览仍显示原始视频，裁剪窗口下方预览为实际保留区域。属性中的文件名会标注已裁剪尺寸。
- 导出时先裁剪各视频源画面，再缩放 / 补边、叠加图片图层；音频保持原有时间轴。图片图层不会随源视频一起裁掉。
- 裁剪视频必须重新编码，即使选择“保持原格式”也不会直接输出未裁剪的原文件。若更改导出画布或选择铺满，最终尺寸和画面取舍以导出设置为准。

## 字幕字体、大小、位置与视频烧录

点击顶部 **字幕样式**：

- 字体：黑体 / 微软雅黑、宋体、楷体、Arial。使用本机字体，缺少指定字体时由浏览器回退；中文系统通常已有中文字体。
- 字号：按画面高度百分比设置，默认 4.5%（1080p 约 49 像素），随导出分辨率等比例变化。
- 位置：上方居中、画面中央、下方居中，或设置水平 / 垂直百分比。数值表示文字块中心，靠边时自动移入画面。
- 支持文字颜色、加粗、黑色描边，长句自动换行。设置应用于所有字幕，立即生效并支持撤销；将播放头移到有字幕的位置可查看效果。

视频导出默认勾选 **烧录字幕到视频**。导出会先完成视频裁剪、缩放和图片叠加，再绘制字幕；字幕变成视频画面的一部分，播放时不需要额外字幕文件，之后也不能关闭。取消勾选即可输出无字幕画面。只有音频导出不受影响。

预览和导出使用同一套 Canvas 字体绘制逻辑，不依赖 FFmpeg 的 libass 或外部字体下载。字幕以透明 PNG 时间序列合成，在起止时间之外使用透明画面；生成后会清理临时字幕文件。文字越多、分辨率越高，准备和导出耗时越长。

主预览以原视频画面比例显示；使用画面裁剪或自定义导出画布时，最终字号、位置和换行按导出画布重新计算。SRT / VTT 只保留文字和时间，不保存这些全局样式。

## FFmpeg.wasm

首次生成视频波形或执行需要 FFmpeg.wasm 的导出时，会从公共 CDN 加载相关资源，因此第一次使用需要网络连接。

## 快捷键

- `Space`：播放 / 暂停
- `← / →`：逐帧
- `S`：播放头分割
- `Delete`：删除选中片段
- `Ctrl + 鼠标滚轮`：缩放时间轴
